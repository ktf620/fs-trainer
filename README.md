# 동물 달리기 500m

레인마다 이름을 적고 출발하면, 랜덤으로 뽑힌 동물들이 그 이름표를 달고 500m 를 달리는 경주 게임.
누가 이길지는 매판 달라집니다.

- 참가 2 ~ 22마리 (동물 150종 가운데 랜덤 — 포유류 · 새 · 파충류 · 바다 동물 · 공룡)
- 동물마다 다른 스킬 · 아이템 12종 · 날씨 7종 · 돌발 상황 9종
- 서로 방해하고 돕기도 하면서 달립니다 (바나나 · 크림 파이 · 번개 / 응원 확성기 · "같이 가자!")
- 순위표에서 이름을 누르면 그 동물을 따라가며 볼 수 있어요

## 파일

- `index.html` — 화면
- `css/style.css` — 꾸밈
- `js/sim.js` — 경주 규칙 (동물 · 스킬 · 아이템 · 날씨 · 돌발 상황). 앞의 50종은 스킬을 하나씩 따로 만들었고, 뒤의 100종은 표(스킬 유형 + 수치)로 정의
- `js/art.js`, `js/art2.js` — 그림 (전부 캔버스에 직접 그림, 그림 파일 없음 · 캐릭터는 이 게임용으로 새로 그린 것)
- `js/render.js` — 경주 화면
- `js/sfx.js` — 소리 (Web Audio)
- `js/game.js` — 화면 흐름

빌드 없이 그대로 열리는 정적 페이지입니다. 이름과 설정은 그 브라우저(localStorage)에만 저장되고 어디로도 보내지 않습니다.

## 밸런스

`js/sim.js` 는 node 에서도 돌아서, 수만 판을 돌려 동물별 순위 분포가 고르게 나오도록 기본 속력을 맞췄습니다
(8마리 · 5마리 · 22마리 판을 섞어 돌리고, 우승률 · 상위권 · 꼴찌 비율을 함께 봄). 날씨에 따라 유리한 동물은 달라집니다.
동물은 판마다 레인에 랜덤으로 배정되므로, 이름(레인) 기준으로는 항상 공평합니다.

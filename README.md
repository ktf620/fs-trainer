# 동물 달리기 1km

레인마다 이름을 적고 출발하면, 랜덤으로 뽑힌 동물들이 그 이름표를 달고 1km 를 달리는 경주 게임.
누가 이길지는 매판 달라집니다.

- 참가 2 ~ 22마리 (동물 150종 가운데 랜덤 — 포유류 · 새 · 파충류 · 바다 동물 · 공룡)
- 동물마다 다른 스킬과 **필살기** · 아이템 12종 · 날씨 7종 · 돌발 상황 9종
- 필살기는 게이지가 차면 터집니다. 게이지는 달리는 동안 조금씩 차고, 뒤처지거나 방해를 당하면 더 빨리 찹니다
  (자리 바꾸기 · 세상 뒤집기 · 운석 · 폭탄 돌리기 · 시간 정지 · 되감기 · 댐 · 물살 · 떼 몰려오기 등 52가지 방식)
- 서로 방해하고 돕기도 하면서 달립니다 (바나나 · 크림 파이 · 번개 / 응원 확성기 · "같이 가자!")
- 순위표에서 이름을 누르면 그 동물을 따라가며 볼 수 있어요. 순위표 아래 줄이 필살기 게이지입니다

## 파일

- `index.html` — 화면
- `css/style.css` — 꾸밈
- `js/sim.js` — 경주 규칙 (동물 · 스킬 · 필살기 · 아이템 · 날씨 · 돌발 상황). 앞의 50종은 스킬을 하나씩 따로 만들었고, 뒤의 100종은 표(스킬 유형 + 수치)로 정의. 필살기는 150종 모두 `ULT` 표에 있음
- `js/art.js`, `js/art2.js` — 그림 (전부 캔버스에 직접 그림, 그림 파일 없음 · 캐릭터는 이 게임용으로 새로 그린 것)
- `js/render.js` — 경주 화면
- `js/sfx.js` — 소리 (Web Audio)
- `js/game.js` — 화면 흐름

빌드 없이 그대로 열리는 정적 페이지입니다. 이름과 설정은 그 브라우저(localStorage)에만 저장되고 어디로도 보내지 않습니다.

## 밸런스

`js/sim.js` 는 node 에서도 돌아서, 수만 판을 돌려 동물별 순위 분포가 고르게 나오도록 기본 속력과 필살기 게이지 빠르기를 맞췄습니다
(8마리 · 5마리 · 22마리 판을 섞어 돌림. 9마리 이상인 판에만 적용되는 게이지 보정이 따로 있음).
맞춘 뒤 따로 돌려 본 결과 (우승률 ÷ 기대 우승률, 1.00 이면 딱 맞음):

- 8마리 8,000판 : 150종이 0.52 ~ 1.44, 그중 145종이 0.6 ~ 1.4 (110종이 0.8 ~ 1.2)
- 22마리 2,600판 : 0.22 ~ 1.94, 139종이 0.5 ~ 1.5 (판 수가 적어 표본 오차가 큼)

필살기 때문에 순위가 크게 뒤집히도록 만들었습니다 (8마리 300판 기준 : 900m 선두가 그대로 우승한 판 31%,
우승자가 700m 에서 하위권이었던 판 40%, 800m 선두가 하위권으로 끝난 판 41%).
날씨에 따라 유리한 동물은 달라집니다. 동물은 판마다 레인에 랜덤으로 배정되므로, 이름(레인) 기준으로는 항상 공평합니다.

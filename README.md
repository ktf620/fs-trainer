# 동물 달리기 1km

레인마다 이름을 적고 출발하면, 랜덤으로 뽑힌 동물들이 그 이름표를 달고 1km 를 달리는 경주 게임.
누가 이길지는 매판 달라집니다.

- 참가 2 ~ 22마리 (동물 150종 가운데 랜덤 — 포유류 · 새 · 파충류 · 바다 동물 · 공룡)
- 동물은 실제 체형으로 그립니다 (네 발 동물은 네 발로, 새 · 물고기 · 뱀 · 공룡 · 게 · 문어는 각자 모양대로)
- 동물마다 **스킬 2개 + 필살기 1개**. 아이템은 없습니다
- 스킬 · 필살기 · 돌발 상황은 **한 번에 하나씩**만 나오고, 그때 화면이 그 동물을 크게 비추며 잠깐 느려집니다
- 코스는 판마다 다른 **지형 구간**(물길 · 모래밭 · 눈밭 · 진흙탕 · 바윗길 오르막 · 내리막 · 숲길)으로 이어지고, 구간마다 유리한 동물이 다릅니다
- 날씨 7종이 경기 중 여러 번 바뀝니다. 돌발 상황 : 벌떼 · 두더지 · UFO · 허들 · 낙석 · 별똥별 · 무지개 · 회오리바람 · 큰 물결 · 눈사태 · 관중 응원
- 필살기는 게이지가 차면 터집니다. 게이지는 달리는 동안 조금씩 차고, 뒤처지거나 방해를 당하면 더 빨리 찹니다
- 순위표에서 이름을 누르면 그 동물을 따라가며 볼 수 있어요. 순위표 아래 줄이 필살기 게이지입니다
- 한 판은 보통 빠르기로 3분쯤. 시작 전에 빠르기를 고르거나, 경기 중 `빠르기` 버튼으로 2 · 3배로 볼 수 있습니다

## 화면

경주 화면은 창 크기에 맞춰 스스로 배치를 바꿉니다.

- **PC · 넓은 화면** : 창 전체를 꽉 채웁니다. 왼쪽이 경주, 오른쪽이 순위와 중계. 큰 모니터에서는 글자와 표시도 같이 커지고, `전체 화면` 버튼으로 브라우저 틀까지 없앨 수 있습니다
- **휴대폰 세로** : 경주가 화면을 거의 다 쓰고, 순위는 아래 한 줄(옆으로 밀어 보기), 중계는 최신 한 줄
- **휴대폰 가로 · 낮은 창** : 오른쪽에 순위만 좁게
- 참가가 11마리 이상이면 이름을 동물 머리 위가 아니라 **왼쪽 이름 칸**에 레인별로 적고, 동물 위에는 번호만 붙입니다 (22마리도 겹치지 않게). 이름 칸에는 지금 1 ~ 3등 표시가 붙습니다

## 파일

- `index.html` — 화면
- `css/style.css` — 꾸밈
- `js/sim.js` — 경주 규칙 (동물 · 스킬 · 필살기 · 지형 · 날씨 · 돌발 상황). 앞의 50종은 스킬을 하나씩 따로 만들었고, 뒤의 100종은 표(스킬 유형 + 수치)로 정의. 필살기는 150종 모두 `ULT` 표에 있음
- `js/art.js` — 동물 그림 (체형별 : 네 발 · 두 발 공룡 · 새 · 바다 동물 · 뱀 · 갑각류 · 문어류 …), `js/art2.js` — 소품 그림 (전부 캔버스에 직접 그림, 그림 파일 없음 · 캐릭터는 이 게임용으로 새로 그린 것)
- `js/render.js` — 경주 화면
- `js/sfx.js` — 소리 (Web Audio)
- `js/game.js` — 화면 흐름

빌드 없이 그대로 열리는 정적 페이지입니다. 이름과 설정은 그 브라우저(localStorage)에만 저장되고 어디로도 보내지 않습니다.

## 밸런스

`js/sim.js` 는 node 에서도 돌아서, 수만 판을 돌려 동물별 순위 분포가 고르게 나오도록 기본 속력과 필살기 게이지 빠르기를 맞췄습니다
(8마리 · 5마리 · 22마리 판을 섞어 돌림). 참가가 9마리 이상인 판에는 따로 잰 속력 보정이 조금 더해집니다. 지형과 날씨에 따라 유리한 동물은 달라집니다.

- 8마리 판 10,000판 : 동물별 우승률이 기대값(12.5%)의 0.63 ~ 1.78배. 150종 가운데 145종이 0.6 ~ 1.4배 안
- 22마리 판 6,000판 : 평균 순위 9.96 ~ 12.77등(가운데 11.5등). 우승률은 기대값(4.5%)의 0.35 ~ 2.33배로 더 벌어지고, 130종이 0.5 ~ 1.5배 안.
  참가가 많을수록 한 방이 있는 동물이 1등을 더 자주 합니다
- 역전 (8마리 300판) : 900m 선두가 그대로 우승한 판 52%, 우승자가 700m 에서 하위권이었던 판 43%, 800m 선두가 하위권으로 끝난 판 21%
- 레인별 우승률은 고릅니다 (8마리 판 11.9 ~ 13.2%)

동물은 판마다 레인에 랜덤으로 배정되므로, 이름(레인) 기준으로는 항상 공평합니다.
